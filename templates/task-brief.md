# 任务输入模板

task_id：  
attempt_id：  
task_spec_sha256：  
contract_sha：  
base_sha：  
工作区与分支：  
角色／请求模型／实际模型：  
执行器版本／主机／资源租约：  

## 目标

引用任务卡的目标与验收标准，不另行扩充。

## 可修改范围

列出规范化后的具体路径；共享文件的处理方式单列。

## 前置材料

产品契约、相关 ADR、依赖提交、原始证据位置与只读参考路径。

## 实现与验证

说明本任务需要的实现资源、验证资源、必要检查和不能以模拟替代的真实任务。

## 预算与子任务

填写时限、用量上限、可用子 Agent 槽位、最大深度和已授权工具。

## 返回结果

按 contracts/worker-result.schema.json 返回；结果文件和事件日志分别保留。没有真实 commit 或检查结果时用 null / not_run，不填示例 SHA。
